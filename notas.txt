#NOTAS DA AULA 1

No GoLang, o agrupamento de campos repetitivos deve ser criado em estruturas de código.

Essa estrutura é conhecida como 'struct'.

As structs devem, obrigatóriamente ter um prefixo e um sufixo:

type <NomeDaEstrutura> struct {
    ... atributos
}

A instanciação de estruturas no Go é feita utilizando chaves:
<NomeDaEstrutura>{campo1: valor, campo2: valor}

Ou

<NomeDaEstrutura>{valor1, valor2}

Não infomar os valores internos da struct, o GoLang atribui por padrão o zero-value:
string = texto vazio
int = zero
float32 = zero
float64 = zero
bool = false

Quando não utilizamos todos os campos da estrutura na inicialização, os demais campos são mantidos com os valores padrão:
type <NomeDaEstrutura> struct {
    campo1 string
    campo2 string
    campo3 int
    campo4 float32
}

str1 := <NomeDaEstrutura>{"valor1", "valor2", 123, 0.0}
No caso acima, estamos criando uma estrutura completa

str2 := <NomeDaEstrutura{campo1: "valor1", campo3: 123}
E no caso acima, apenas uma estrutura com o campo1 e o campo3, onde o campo2 e o campo4 estão com os valores padrão

#NOTAS DA AULA 2
Podemos instanciar objetos utilizando o operador 'new':
var <nome> <NomeDaEstrutura>
<nome> = new(<NomeDaEstrutura>)

Contudo, precisamos indicar para a variável, que ela apontará para uma instância que será criada na sequência, usando o operador '*':
var <nome> *<NomeDaEstrutura>
<nome> = new(<NomeDaEstrutura>)

Logo, um exemplo prático seria:
var conta *ContaCorrente
conta = new(ContaCorrente)

Utilizando a saída do console, temos:

fmt.Println(conta) //&{atributos} - Imprime o ponteiro e o conteúdo do espaço alocado em memória
fmt.Println(&conta) //0xc99999999 - Imprime o endereço de memória
fmt.Println(*conta) //{atributos} - Imprime o conteúdo do espaço alocado em memória

Ao compararmos dois objetos com o mesmo conteúdo, o Go retornará true, pois o Go é inteligente pra saber que, estamos comparando o conteúdo e não o endereço de memória:
fmt.Println(conta == conta2) //true

A comparação acima retornará true para a instanciação de objetos usando:
conta := ContaCorrente{campo: valor [...]}

E
conta := ContaCorrente{valor, [...]}

Mas retornará false para a instanciação usando:
var conta *ContaCorrente
conta = new(ContaCorrente)

Isso ocorre pois a criação utilizando new() instancia também um novo endereço na memória do programa.

Podemos criar funções que vão atuar exatamente no ponteiro que chamou a função. Assim, não precisamos passar uma referência do objeto para a função, ou seja, podemos substituir isso:
func withdraw(valor float64, conta ContaCorrente) {...}

Por isso:
func (conta *ContaCorrente) withdraw(valor float64) {...}

#NOTAS DA AULA 3
Quando queremos alterar o conteúdo de uma instância utilizando as funções, não podemos esquecer de apontar a variável para o ponteiro que contém o endereço do objeto:
origem.Transferir(300, destino)

func (origem *ContaCorrente) Transferir(valor float64, destino *ContaCorrente) {...}

Caso esqueçamos de utilizar o ponteiro (*), a operação não afetará o objeto de destino:
origem.Transferir(300, &destino)

Distribuição do Sistema em Pacotes

Para segregarmos o nosso sistema em pequenos pacotes, basta criarmos uma pasta com o nome do nosso pacote e criar um novo arquivo com a extensão .go:
/src/<project>/<package>/file.go

No nosso arquivo do programa, precisamos indicar o endereço onde o pacote se encontra desde a raiz do projeto:
/src/<project>/<package>/file

E ao utilizar qualquer recurso do 'file', temos que indicar também:
conta := file.ContaCorrente{}

Não podemos esquecer também da visibilidade dos pacotes e atributos. No Go, quando uma variável de instância é criada com a primeira letra em minúsculo, isso significa que a variável de instância só é visível dentro do próprio arquivo onde ela é declarada.
type ContaCorrente struct {
    titular string
    agencia int
    conta int
    saldo float64
}

Para tornarmos a variável de instância visível pra outros locais, basta criarmos a variável com a primeira letra em maiúsculo.
type ContaCorrente struct {
    Titular string
    Agencia int
    Conta int
    Saldo float64
}

Para tornar ainda mais fácil a utilização de pacotes no Go, podemos criar um alias para a importação de pacotes:
import (
    file "/src/<project>/<package>/file"
)

E para usá-lo, basta referenciarmos o alias 'file', assim:
file.ContaCorrente{}

No Go, podemos utilizar funções que alteram o valor do objeto original ou que alteram a cópia do  objeto original.

Quando queremos alterar o objeto original, nas funções ou métodos, precisamos indicar o ponteiro a qual a função atuará:
func (empregado *Empregado) aumentarSalario(valor float64) {
    empregado.AumentarSalario(valor)
    fmt.Println("Novo salário do funcionario", empregado.ObterSalario())
}

No caso acima, estamos alterando o salário do funcionário diretamente em sua referência. Veja abaixo:
empregado1 := Empregado{Nome: Rafael, Salario: 1000}
empregado1.AumentarSalario(1000)
empregado1.ObterSalario() //Vai imprimir 2000: 1000 original + 1000 do aumento

Veja esse outro caso:
func (empregado Empregado) aumentarSalario(valor float64) {
    empregado.AumentarSalario(valor)
    fmt.Println("Novo salário do funcionario", empregado.ObterSalario())
}

No caso acima, estamos criando uma cópia do objeto empregado e atribuindo à variável 'empregado' do método. Consequentemente, o salário original, não será afetado:
empregado1 := Empregado{Nome: Rafael, Salario: 1000}
empregado1.AumentarSalario(1000)
empregado1.ObterSalario() //Vai imprimir 1000: 1000 original

#NOTAS DA AULA 5
No Go, podemos declarar variáveis do mesmo tipo usando o separador vírgula (,):
type ContaCorrente struct {
    NumeroAgencia, NumeroConta, Operacao int
    ...
}

Existem situações onde temos operações que serão comum para mais de um tipo de struct. Um exemplo disso são as operações:
- Transferir
- Depositar
- Sacar
- Pagar

Todas as operações acima listadas, podem ser realizadas tanto numa Conta Corrente, quanto numa Conta Poupança.

O que queremos aqui é, chamar a operação e internamente a operação resolve se é uma CC ou uma CP.

Nessas situações, vamos utilizar o tipo 'interface' criando um novo tipo de estrutura:
type Conta interface {
    PagarBoleto(valor float64)
}

As structs que farão uso da função PagarBoleto, devem respeitar a assinatura definida na interface:
func PagarBoleto(conta Conta, valor float64) {
    conta.PagarBoleto(valor)
}
